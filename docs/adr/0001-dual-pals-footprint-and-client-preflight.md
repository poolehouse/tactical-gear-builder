# Dual PALS Footprints (Attachment vs. Material Coverage) and Client Pre-Flight Gating

Components mounted on a 1x1 PALS Grid declare both an `AttachmentFootprint` (`cols x rows` of webbing channels woven into the slot) and an optional `MaterialCoverage` (`cols x rows` plus `offset_col` / `offset_row` describing the physical body/fabric envelope). While the `AttachmentFootprint` must stay strictly within the PALS Grid boundaries, `MaterialCoverage` may overhang past the outer edge of the grid and marks in-bounds cells as covered so adjacent pouches and tools cannot physically collide with overhanging gear. The 2D canvas pre-evaluates this dual-footprint rule client-side (`is-blocked`, `aria-disabled="true"`, red invalid hover preview, click/drop no-op) and exposes all mounted items in the Slot Panel so occluded mounts remain selectable without relying on z-index click-through.
